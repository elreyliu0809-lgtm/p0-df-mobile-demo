# 拾火成器 · PG-R01 手机网页

在手机浏览器打开版本入口，选择主武器，再点“装备并进入试炼”。在场地拖动移动，攻击自动进行；电脑也可用WASD或方向键。暂停键可暂歇。

击杀留下金色余辉，要走近才加经验。够经验时原战场冻结，三选一后继续。主武器始终保留，最多两个辅助叠加：环刃接触伤害、余火固定区域延迟脉冲、拒环零伤推离。清场后收完资源进入下一段。保留三主武器与双阶段守门者，以及真实胜败和重新装备。

原创离线机制候选，参数、关卡长度与两辅助上限为实验切片。来源候选已经完成本地同包独立复测，手机网页另按最终静态字节复测；物理手机与人类乐趣/平衡接受不由此推导。没有游戏模型外呼或服务器存档，刷新会回准备页。本页不连接公司模型、账号、商业或正式游戏服务。

运行代码位于根目录 core.mjs、growth.mjs、encounter.mjs、projectile.mjs、ui.mjs 和 view.mjs，公共依赖在 vendor-js/。public-manifest.json 记录本版本公开文件字节。此版本独立保存，不覆盖其他体验版本。
